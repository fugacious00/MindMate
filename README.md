# 🧠 MindMate - Your Mental Wellness Companion



> **Making mental health support accessible, affordable, and beautiful for everyone**



## 🎯 What is MindMate?

MindMate is a comprehensive **mental wellness platform** that empowers you to take control of your mental health with privacy, ease, and AI-powered support.

### ✨ Core Features

- 📊 **Mood Tracking** - Track emotional patterns and identify triggers
- 📔 **Private Journaling** - Write and reflect on your thoughts securely
- 😴 **Sleep Monitoring** - Track sleep quality and patterns
- 🎯 **Habit Building** - Build positive habits with visual streaks
- 🧠 **CBT Exercises** - Guided therapeutic techniques
- 🤖 **AI Companion** - 24/7 TheraBot for mental health support
- 🔒 **100% Private** - All data stored locally, zero cloud sync
- 📱 **Offline First** - Works without internet connection




## 🚀 Quick Start

### Get the App Running

```bash
# Clone & install
git clone https://github.com/mindmate/mindmate.git
cd mindmate-app
npm install

# Start development
npm run dev
```

Open `http://localhost:5173`

### Get the Website Running

```bash
cd mindmate-website
npm install
npm run dev
```
